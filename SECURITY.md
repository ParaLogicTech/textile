# Security Policy

This repository is textile, ParaLogic's textile manufacturing app. We take security issues in it seriously.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ParaLogicTech/textile/security/advisories/new)
(Security tab → "Report a vulnerability").

Include the affected branch and commit, steps to reproduce and the impact you expect. We'll acknowledge the report,
keep you updated, and credit you in the advisory if you'd like.

## Issues in Frappe or ERPNext

textile runs on ParaLogic's forks of Frappe and ERPNext. Report an issue in one of those to the fork's repository
([ParaLogicTech/frappe](https://github.com/ParaLogicTech/frappe/security/advisories/new),
[ParaLogicTech/erpnext](https://github.com/ParaLogicTech/erpnext)). If it also exists in stock Frappe or ERPNext,
please report it to Frappe as well, following [Frappe's security policy](https://frappe.io/security).

## Supported versions

Only the `version-15` branch receives security fixes.
